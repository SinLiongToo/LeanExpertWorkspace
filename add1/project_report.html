How to Use This Report

Top Right Buttons

📋 Demo — Loads sample project data so you can see how the report looks when filled in.

✨ Clean — Wipes all current data and gives you a blank project to start fresh. Use this before entering your own data.

🌙 / ☀️ — Toggles dark/light mode. Your choice is remembered.

Tabs

Overview — Read-only summary of everything: project info, status, background, lowlights/issues, all milestones, and all actions. This is the page to review or print.

Milestones — Add or delete milestone entries (name, week, status).

Actions — Add or delete action/recommendation entries (action, owner, due date).

Edit — Update core project fields (name, manager, BL/PL, owner, DRI, objective, background, status, lowlights).

Help — This page.

Typical Workflow

1. Click ✨ Clean to start a new project.
2. Go to Edit and fill in project details, then click Save Changes.
3. Go to Milestones and click + Add Milestone for each milestone.
4. Go to Actions and click + Add Action for each action item.
5. Check Overview to review the full report.
6. Click Export JSON (in Edit tab) to save a backup file.

Saving & Loading Old Projects

Export JSON — Downloads your current project as a .json file. Keep this file safe as your backup.

Import JSON — Upload a previously exported .json file to restore that project. This replaces whatever is currently loaded, so export first if you want to keep it.

Your data also auto-saves to this browser via localStorage, so closing and reopening the page keeps your data — but only on the same browser/device. Use Export/Import to move data between devices or keep permanent backups.
